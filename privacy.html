Privacy

This website does not use analytics and does not track email clicks, outbound links, file downloads, or scroll depth. It sets no cookies, and every file it needs to display a page, including its fonts, is served from this site itself. No third party is contacted while you read it.

The site is hosted on GitHub Pages, so GitHub receives and logs standard browser request information, including your IP address, when you open a page.

The site links out to external services such as GitHub, ORCID, Google Scholar, LinkedIn, Harvard Dataverse, and publishers. Dataset links go through doi.org, which redirects to the repository holding the data. Those services may receive standard browser request information when you open their links.
